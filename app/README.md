# App Structure

This folder is reserved for the assistant application.

## Suggested modules
- `ui/`: Electron window layout, panels, settings, notifications, permission dialogs
- `backend/`: Flask API surface, session handling, streaming, and local app coordination
- `voice/`: speech input, speech output, wake flows, device handling
- `assistant/`: orchestration, task routing, memory, session state
- `automation/`: desktop control, app actions, file and browser operations
- `integrations/`: external systems and service connectors
- `safety/`: permissions, policy checks, audit logging, emergency stop
- `shared/`: common contracts, schemas, prompts, constants, and documentation

No implementation code has been added yet.
